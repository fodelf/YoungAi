## 重新生成

依赖：`python-docx`、`matplotlib`（画图）、LibreOffice（转 PDF / 数页数）。

```sh
python make_figs.py                     # 重画两张图 -> figs/
python build_doc.py                     # 套模板生成 docx（模板在仓库根目录）
soffice --headless --convert-to pdf --outdir . 开放探索赛初赛问题定义文档.docx
```

改正文只需编辑 `build_doc.py` 里的 `BODY` 字典（键 = 模板中对应「应说明」段落的索引）。
**改动后务必重转 PDF 复核页数**——4 页是硬性要求，正文与图的尺寸都卡在边界上。
