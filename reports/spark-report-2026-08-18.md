## 二、速度实测

| 场景 | 实测 |
|---|---|
| 单场景 CLI（贪心，48 tok） | **30.9-31.4 t/s** |
| 单场景 server 口径（200 tok） | 25.1-27.3 t/s |
| 4 并发（4×200 tok 同发） | **聚合 27.9 t/s**；每流 7.0/9.3/14.0/28.0（串行排队阶梯） |

- 单场景 80 的物理账：单 forward 墙 ~49 t/s（5.2GB/token ÷ 255GB/s 实测 kernel 读极限）。
  80 唯一路径 = DSpark 投机（块 5+bonus，社区代码域接受率 0.88-0.92，账面 ~2.5×）。
- 4×60 需要 request-batching（当前 server 单 graph worker 串行是结构性的），
  这是 DSpark 之后的下一工程。
