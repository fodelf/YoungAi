# 商业计划书（BP）
## DwarfStar：消费级设备上的大模型私有化 —— 成本降两个数量级

> 版本 v0.1 · 2026-07-22

---

## 1. 一页摘要

**一句话**：我们把千亿级参数的大模型装进 2–3 万元的消费级电脑，质量接近原始模型、速度达到可用——让大模型私有化的门槛从"百万元级机房工程"降为"买一台电脑插电即用"。

**核心卖点就是一张成本表**：

| 私有化方案 | 硬件投入 | 功耗与运维 | 部署形态 |
|---|---|---|---|
| GPU 服务器满血部署 | **100 万元起** | 数千瓦，机房托管 + 专人运维 | 机房工程 |
| 市场主流一体机 | 几十万–数百万元 | 机房级 | 整机采购 |
| 顶配消费机跑满血模型 | 7.5 万元级（512GB 顶配） | 数百瓦 | 桌面设备 |
| **我们：压缩 + 还原** | **2–3 万元级（64GB 级消费设备，Apple / NVIDIA 平台均支持）** | 约两百瓦，家用电源即插即用 | **桌面设备** |

相对 GPU 服务器方案，**硬件成本下降 30–50 倍**，且无机房、无专人运维；相对"顶配消费机跑满血"，成本再降一半以上，并且我们额外提供质量还原、速度优化和按客户定制的能力增强——这些是裸硬件方案给不了的。

**市场**：政企大模型一体机市场机构预测 2025–2027 年达 1236 / 2937 / 5208 亿元，近百家厂商入局但严重同质化，全行业都缺一个真正的成本/差异化杀手锏。

**为什么是现在**：中国开源模型（DeepSeek、GLM、Kimi）2026年中才刚刚跨过"真正能写代码"的门槛。**早一年做，模型写不了代码，压下来也没有商业价值；晚一年做，卡位被抢。我们正踩在能力拐点上。**

**当前进展**：核心技术链路已全部跑通，压缩后的模型已在消费级硬件上实现真实的编程智能体多轮工具调用；当前完整支持 DeepSeek 系列，GLM、Kimi 适配作为并行主线贯穿三个月持续推进（见 §7）；正在向可商用的质量与速度基准冲刺。

**本轮方案**：估值 500 万元，释放 10% 股权；首笔 10 万元启动，三个月三个里程碑（demo → 基准测试 → 商业化发力），不达标全额回购退款，达标后完成本轮正式投资。

## 2. 我们做什么

### 2.1 消费级设备跑真正的大模型（成本故事的来源）
前沿 AI 能力今天只存在于千亿级参数的大模型里。我们不做"小模型替代"——小模型能力上限摆在那里；我们**把真正的大模型压下来**，体积压缩到满血部署的十分之一以下，落在 2–3 万元的消费机上单机运行，支持超长上下文，数据永远不出办公室。

### 2.2 质量还原 + 速度优化（自研核心技术，机制不对外披露）
- **质量**：压缩必然损伤质量，我们的自研还原技术把质量拉回接近原始模型水平——**全程不需要 GPU 集群、不需要重新训练**：已适配架构族的新版本跟进以周计、成本以千元计，新架构族的首次适配以月计。这意味着模型厂每出一代新模型，我们都能快速跟进，产品永远搭载最新的前沿能力。
- **模型路线**：当前完整支持 DeepSeek 系列；GLM、Kimi 适配作为并行主线贯穿三个月持续推进（见 §7）——目标是中国开源编程模型三强全覆盖，客户按需选基座。
- **速度**：自研提速技术已在编程场景实测取得**数倍加速**，使压缩模型在目标硬件上达到可用的交互体验。
- 配套一整套可复现的质量评测体系，每次交付质量有据可查。
- 核心技术均为自研管线，**只交付结果、不交付方法**；具体机制作为商业秘密保护，投资尽调阶段可在保密协议下演示验证。

### 2.3 按客户定制的能力增强
在压缩基座之上，我们能为客户增加原模型没有的能力：行业专精、贴合客户代码库的编程助手、稳定可靠的多轮智能体行为、定制交付风格。以**定制项目**交付，能力更新随 OEM 年度授权持续提供——这同时是商业上的护身符：即使模型文件被复制，定制能力的生产管线永远在我们手里，客户买到的不是一个静态文件，而是持续的能力演进，而演进只能来自我们。

## 3. 市场与时机

| 市场 | 数据 | 来源 |
|---|---|---|
| 政企大模型一体机 | 2025–2027 预测 1236 / 2937 / 5208 亿元；出货 15 / 39 / 72 万台 | 浙商证券（经东方财富转引） |
| 供给侧 | 近百家厂商入局，几十万–数百万元/台，严重同质化 | IDC |
| 企业 AI Agent 定制 | 中高级项目 15–40 万元/单 | 行业公开报价 |
| 消费硬件路线已被验证 | 高配 Mac 跑满血大模型被媒体称"性价比最高一体机" | 36氪等实测 |

**客户为什么买**：不是省钱（API 很便宜），是**数据不出域**——律所、医院、设计院、涉密软件企业的合规刚需。我们把满足这个刚需的价格从百万级打到万级，让原本买不起私有化的中小机构第一次买得起。

**我们是"中国开源模型水涨船高"的故事**：模型能力的上涨由 DeepSeek、GLM、Kimi 投入数十亿研发完成，我们不承担模型研发的资本和风险；我们的免训练管线把每一代新模型快速装进万元硬件（已适配架构的版本跟进以周计，新架构首次适配以月计）。**上游模型每变强一次，我们的产品跟着变强一次**——研发投入是模型厂的，能力红利是我们和客户的。水位只会涨不会退，我们的船造好了就一直在水上。

**为什么是现在（时机的唯一性）**：中国开源模型 2026 年中才刚刚跨过"真正能写代码"的门槛——在此之前压缩没有商业意义（模型本身干不了活），在此之后入场则错过卡位。**前面做没用，后面做晚了，现在是唯一的窗口。** 叠加三个外部信号：私有化需求处于高位；极限压缩是全球热点方向（微软同方向项目 2026 年初登顶 GitHub 趋势榜）；压缩技术公司被 Red Hat、NVIDIA 相继收购，证明赛道有真实买家。窗口期 18–24 个月，需要快速卡位。

## 4. 产品与商业模式

| 产品 | 形态 | 收费 |
|---|---|---|
| P1 压缩基座 | 压缩模型 + 运行时，预装进 OEM 硬件 | OEM 年度授权 50–200 万/家，或按台抽成 |
| P2 能力定制 | 按客户行业/代码库定制，更新随年度授权持续提供 | 定制项目 15–40 万/单 |
| P3 私有编程助手 | 基座 + 定制能力 + 智能体的整机交付 | 随 OEM 整机出货或灯塔客户直签 |
| P4 压缩服务 | "把你选的模型压进你指定的硬件预算" | 项目制 |

**目标客户**：二线一体机厂商与行业软件商（缺差异化、决策快），它们是客户不是对手。运行时跨 Apple 与 NVIDIA 硬件——**厂商可直接基于 NVIDIA 平台攒机预装**，不受苹果整机渠道限制。

**单位经济**：软件 + 求解服务，无算力成本，毛利率 >90%。

## 5. 竞争与壁垒

- 免费工具（Ollama / LM Studio / llama.cpp 生态）：对千亿级模型的最小可用量化体积约为我们的 **3 倍**，根本进不了 64GB 消费机档位——**在我们的目标硬件档上，免费方案跑不了前沿大模型，只能退到中型模型**；且通用压缩质量损失大、无还原、无定制能力，是工具不是交付；
- 微软原生 1-bit 路线：只有从头训练的小模型；我们直接吃现成的前沿大模型；
- 模型厂小模型：能力上限受体积限制；我们交付"压下来的前沿大模型"+ 按客户定制；
- 中国模型厂（DeepSeek / 智谱 / 月之暗面）：是我们的上游水源，不是对手——它们负责能力上涨，我们负责"最后一公里"落进万元硬件；
- 一体机厂商：同质化竞争中的采购方，不是对手。

**壁垒**：不在单点算法，而在完整生产管线（商业秘密，不开源不交付）+ 质量评测体系 + 年度授权与持续定制的客户绑定 + 窗口期内的 OEM 先发卡位。

## 6. 本轮融资方案（核心条款）

**估值 500 万元，本轮释放 10% 股权（50 万元），分两笔、里程碑对赌：**

### 首笔：10 万元（含回购保障）
| 时间 | 里程碑 | 验收标准 |
|---|---|---|
| 第 1 个月 | **基础 demo** | 单机消费硬件、不剪辑录屏：编程智能体在真实项目上完成"读错误→查代码→改文件→跑测试"闭环 |
| 第 2 个月 | **基准测试** | 出具质量/速度基准报告，对照商用门槛（可用性面板、智能体行为、演示场景速度），第三方可复现 |
| 第 3 个月 | **商业化发力** | 接触 3–5 家目标 OEM/行业软件商，取得至少 1 个付费意向或 POC 合作 |

**对赌条款**：第 3 个月末未达成验收标准，创始人**全额回购退还 10 万元**；投资人零技术风险试水。

### 正式投资：里程碑达成后
- 以同一估值（500 万）完成本轮剩余 **40 万元（8%）**——里程碑达标后 **30 天内**完成，逾期该跟进权失效、估值重议；
- 资金用途：公司主体与知识产权落地、交付工程、商务推进；
- 后续轮：首张 OEM 付费合同落地后启动下一轮（估值随收入验证上调，参照压缩赛道公司数千万级融资轨迹）。

### 为什么这个结构对投资人有利
- 10 万试水 + 回购保障 = 下行风险封底；
- 三个月三个可验收节点，每一步都有明确判据，不是"投了等消息"；
- 500 万估值是刻意保守的入场价——同赛道公司（被 Red Hat/NVIDIA 收购的压缩技术公司）融资起点多为千万美元级。

## 7. 三个月执行计划

**第 1 个月 · 基础 demo**
- 收口单机配置（64GB 级消费硬件），打磨编程智能体端到端演示；
- 产出：不剪辑演示录屏 + 可现场复演的环境。

**第 2 个月 · 基准测试**
- 全域质量面板 + 智能体行为测试 + 速度基准，形成对外报告。

**第 3 个月 · 商业化发力**
- 携 demo + 基准报告 + 成本对比表接触 3–5 家二线一体机厂商/ISV；
- 目标：1 个付费意向或 POC；同步完成公司主体注册与知识产权申请。

**贯穿三个月 · GLM / Kimi 适配（并行主线）**
- 与上述节点并行持续推进，不挤占各月主线交付；
- 阶段目标：第 1 个月完成架构分析与适配启动 → 第 2 个月 GLM 管线跑通验证（证明是平台，不是单一模型的手工品）→ 第 3 个月 Kimi 跑通，商务谈判时"三强全覆盖、客户按需选基座"成立。

## 8. 团队与资金用途（首笔 10 万）

- 现状：创始人单人全栈，从推理引擎到压缩管线到评测体系全链独立完成，工程速率已被项目本身验证；
- 首笔 10 万用途：三个月全职投入的基础开销 + 演示/测试硬件补齐 + 基准报告制作；
- 正式投资后优先补位：**商务/BD 合伙人**（闭源直销路线下比第二个工程师更重要）、交付工程师。

## 9. 风险与应对

| 风险 | 应对 |
|---|---|
| 质量/速度未达商用线 | 三个月对赌结构本身就是止损机制：不达标退款，投资人无损失 |
| 模型厂出新一代模型 | 水涨船高结构：已适配架构周级跟进、新架构月级适配，上游每次升级都是我们的产品升级——风险反转为红利 |
| 模型文件被复制 | 收入挂在年度授权与持续定制服务上，核心管线永不交付——复制走的只是一个会过时的静态文件 |
| 技术泄密 | 核心机制不写入任何对外材料，尽调验证在保密协议下进行；只演示结果不讲方法 |
| 单人团队 | 全链已脚本化、文档化；正式投资后第一件事补合伙人 |
| 窗口期关闭 | 全部节奏压缩在月级推进，对赌节点即卡位节点 |

**失败模式的诚实说明**：即使商业化不成，压缩技术资产本身在收购市场有明确参照（同类公司均被大厂收购退出），下行不归零。
