# 量化方案 v2.1 设计（2026-07-25 深度研究修订）——目标：还原率 0.70 → 0.78+

证据基础：`research/quantv2-deepresearch-2026-07-25.md`（110 条带引文论断, 19 条对抗核实：4 毙 15 存活）。本文件只留决策；数字与出处见研究报告。

## 0. 出发点（v1 定格）

v1 = 冷192 signref 1-bit + 热64 go2b 标量2-bit + 合并态联合拟合 + 顺序补偿。
实测：编程域 Σmin=0.696 / top1=72.4% / PPL×2.26；长尾 0.396。
瑕疵归因实锤：残余错误主要=量化 top1 翻转。
**天花板不在拟合纪律（合并态≈GPTAQ, ICML25 才发表的同构方法），在表示能力：无旋转、CIQ=2 的 sign 冷专家、标量热专家、粗二档分配。**

## 1. v2.1 架构（等体积、全零训练）

```
┌ 预处理(热+冷): ★块对角 sequency-Walsh 旋转(GSR 式), 块=量化组
│    非全局 RHT——块对角在 2-bit 实测比全局 Hadamard ppl 减半且 kernel 更便宜;
│    sequency 行重排再免费加档; 折进权重, 激活侧 per-group 前变换 O(d·G)
├ 热64:  2-bit + GPTAQ 式内环(漂移输入 X̂ → FP 参考输出目标 + 残差项 r·XᵀH⁻¹)
│    二阶段升档: TCQ/trellis 或每组格码本(高斯化后标量失真 −40% 空间)
├ 冷192: ★HBLLM 式 Haar 小波分带 + 行内自适应分组 sign 量化
│    CIQ 2 → ~10³ (v1 冷专家最大表示缺口); O(d) 滑窗核, dequant 便宜
│    + 结构化显著列 4-bit 钉扎(1-D 通道 mask, 0.0002 bpw)
│    + 同频带共享均值(−0.25 bpw 回血, 抵钉扎体积)
├ 分配:  ILP {1,2,3}-bit, linear-block 粒度(gate/up/down 分开评),
│    重要度 = 权重离群分 0.8 + 激活频率 0.2, 深度感知(浅层优先加位),
│    热 tier 加宽优于加深; 等体积硬约束
└ 链条:  合并态顺序补偿(v1 已证保留) + per-layer 阻尼 α∈[0,1]
     (2-bit 全强度补偿有实测翻车例) + 拟合目标审计(禁朝漂移伪目标拟合)
```

关键修订 vs v2.0：全局 RHT → 块对角 sequency-Walsh（原"MVP 妥协"实为文献更优解）；冷专家从"旋转+sign"升级为小波分带结构化二值；GPTQ 内环 → GPTAQ 非对称目标；分配从热/冷二档 → linear-block ILP；反修加阻尼。

## 2. 预期收益（文献锚定，非承诺）

- 块对角旋转：2-bit GPTQ 栈单项实测 −43% ppl（dense）
- 冷 1-bit 结构化：匹配位宽实测 −33~66% ppl（dense）
- MoE ILP 分配：等预算 +5~20 分（≤64 专家 MoE；专家越多增益越大, 256 专家外推）
- 综合目标带：Σmin 0.696 → **0.75–0.80**；长尾 0.40 → 0.5±
- 全部文献证据在 dense / ≤64 专家；我们的 256 专家 1.29 bpw 是外推区，以 G1 实测为准

## 3. 执行门序（可用性铁律 + 10 分钟验证总纲）

1. **G1a 量化器侧分钟级 A/B（不动引擎）**：单层输出 cos——
   a) 块对角 sequency-Walsh + go2b vs 裸 go2b（热路线判决）
   b) HBLLM 式小波 1-bit vs signref-1bit（冷路线判决）
   c) 显著列钉扎 1% 增益单测
2. **G1b**：quant_apply 内环目标形式审计（须=FP 参考输出）+ 反修阻尼 α 扫 {1.0,0.7,0.5}
3. **G2 rr 判决**：赢家配置 3 层小样 → 全层 → rr_code smin vs 0.6959
4. **G3 引擎 kernel**（只给 G2 赢家投入）：块对角激活前变换 + 小波 dequant（Metal + CPU gather）
5. **G4 真实编码探针**（铁律判据）：gen_coding_probe 三任务 + LRU 翻转点归因复测
- 盘/内存账每步前置；全程 fable5 记录；原始输出必贴。

## 4. 已否决/后置（含深研击毙项）

- PTQ1.61 / BTC-LLM 头条路线：头条数字含训练组件（LoRA 预处理 / Adam 学变换），零训练判据毙；仅其结构件（1-D 通道 mask / 二值码本）可移植
- PTQTP：真实体积 ~3.17 bpw 超预算（"1.58"是品牌非存储）
- FrameQuant：≥2.0 bpw 起步且解码要帧变换，不适配冷预算
- 数据感知自适应变换（WUSH 类）：GPTQ 栈上边际收益缩 4×，后置
- 低秩边因子（CALDERA 族）：2-bit 纯 PTQ 下输给旋转+码本，且违"加体积=偷懒"铁律，默认不买
- 学习型旋转（SpinQuant/HARP）：需训练，二阶；GSR 可作其免训练替代（差距已很小）
- BitNet/QAT 族：需训练，违零训练约束
- 后训练（corr 激活空间）：双栈双秩四点已 NO-GO，不复活
