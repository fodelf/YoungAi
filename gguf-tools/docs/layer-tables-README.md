# 逐层元素表 —— 项目第一原则(2026-07-11 定)

每一层的量化工作以**本目录一层一个表格文件**(`L00.md`…`L42.md`)为唯一进度与判决载体。规则:

1. **列**:`元素 | 算法 | 体积 | 实测数值 | 还原口径 | 判定`。
2. **所有元素必须有体积**(字节数,量化进模型/侧车的真实开销);离线求解器类元素(四损失/感知)体积记 0,并注明其增益编码进哪个元素的字节。
3. **数值全部真实**:每个数字可回溯到原始输出文件(表尾注明路径);禁止任何推断值/编造值入表。
4. **正向表达**:提升一律写正数(误差下降 X% = 提升 X%)。
5. **判定只有两种**:`✓ 正向`(有实测正数)/ `探索中`(代码在跑测试,不是搁置);负数=形态不对,换算法继续,**不存在"无提升→丢弃"**。
6. **还原度口径**:只有"对比原始完整大模型"的数字可称还原度;单层探针数字标注"单层口径"(该层量化、其余层 FP)。
7. **每层收口产物**:该层量化文件(DQL1:signref 全量字节 + 动态侧车载荷),表格末行记录文件路径、字节数、校验。

元素全集(用户设计):1bit 底座、z 隐变量(乘法族)、向后、分类损失、固定损失、光滑损失、对齐损失、感知。加法元素已裁决删除(2026-07-11,代码 DS4_ADD_FORMS 默认关)。
