# R30 联合损失反修 — 落地文档(2026-08-05 用户架构终裁)

## 裁决背景
- 网格版(13 组互斥选一)实测:粗筛账面 +50% 但端到端 KL 0.390 差于精简版 0.377。
- 双病因:①λ 公式把默认组扭曲(已修:df 锚定 `lsm/0.1`);②**结构缺陷=选择噪声**
  (粗筛 79 行的测量噪声 > 组间真实差 → argmax 挑中噪声正偏组,终判回归。
  证据:两版粗筛累计几乎等(4.361 vs 4.303)而终验差 3.4%)。
- 用户终裁:**"z 变量、路由反修、四损失、感知应该是一起作用的"** —— 网格选一=割裂,
  正解=联合目标函数,四项同时在场。

## 联合目标函数(每个动态形态的单次求解)
```
min_z  Σ_s (1 + W_pc·kk_s) · ‖pred_s(z) − tgt_s‖²  +  λ·lfix·(‖z‖² 截距 + (lsm/0.1)·‖z‖² 非截距)
        └感知/分类行权,恒开┘  └── 对齐损失主项 ──┘      └──── 固定 + 光滑,恒在 ────┘
```
- **对齐** = 最小二乘主项(恒在);
- **感知/分类** = 行权 `1+W_pc·kk_s`(kk_s=行残差能量/行目标能量,残差大的行话语权大;恒开);
- **固定/光滑** = ridge λ 结构(df 锚定:lfix=1.0, lsm=0.1 时逐位等于基线解);
- **超参=全局常数**(不逐层网格挑):`DS4_JOINT_WPC`(默认 0.35,ALT 实证最低有效档)、
  `DS4_JOINT_LFIX`/`DS4_JOINT_LSM`(默认锚定档)。W_pc→0 时逐位退化为精简版解。

## 与网格版的差异
