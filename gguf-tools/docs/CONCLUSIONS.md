## 0. 一句话结论

**纯 1-bit 不可用(R² 39% / 部署 PPL 1620万)。恢复质量本质上需要"位/体积"——极小体积的低秩隐变量补不回。唯一可用的正解是【逐层动态混精度】:无损层真 1-bit + 差层/深层 2-bit。**

"隐形的手"z 的方向(语法在输出空间、低维、可泛化)被证明是对的,但**强度不足以补回真质量**,只够让 1-bit 输出"更像 FP"(装饰性 +2.6%),不能替代加位。

## 1. 量化质量真相(指标先校准)

### 1.1 历史数字是灌水的
之前的"还原率 79–81% / cos 0.92"是假象,被四重灌水:
1. **cos 指标太宽松**:1-bit 保留符号,cos 主要吃符号 → 虚高;幅度全丢了(relL2≈0.78)看不见。
2. **FP shared expert 未量化**:MoE 输出里含相同的 FP 共享专家,把 cos 抬高。
3. **teacher-forced**:每个位置看真实上文,误差不累积(真实生成会累积)。
4. **样本太小**(7–39 token)。

### 1.2 诚实指标 = R² 解释方差(routed-only)
`R² = 1 − relL2²`,只测 routed 专家部分(减掉 FP shared),幅度感知。实测(L0,held-out):

| 配置 | 位宽 | R² 质量 | 说明 |
|---|---|---|---|
| 纯 1-bit(joint-LS scale) | 1-bit | **39.0%** | 1-bit 就该这么差 |
| + 感知(joint-LS 激活感知 scale) | 1-bit | 49.4% | +10.4 点 |
| + Q2 残差量化 | **2-bit** | **78.1%** | **≈可用线** |
| + Q3 残差量化 | 3-bit | 88.8% | +10.7 点 |

**结论对上直觉:1-bit 到不了 80%,2-bit 才到。**

### 1.3 部署真值印证(ds4 引擎, teacher-forced PPL)
- 纯全-1-bit（ds4-code-dyn 42.5G,量化 backbone）: **PPL = 16,203,028 = 垃圾**,生成 `---|---|---` 乱码。
- mixed(1b 浅 + 2b 深,mono-mixed）: **PPL = 6.47 = 可用**,双机跑通 twoSum。
- 唯一变量 = 深层 1-bit vs 2-bit → **纯 1-bit 深层灾难崩坏,深层必须 2-bit**。

## 3. "隐形的手" z 探索(方向对·强度不足)

用户洞察:代码有语法规律→低维→存在一只"隐形的手"z 控制它,用四损失定向优化。

### 3.1 找对了位置
- ✗ **不在权重残差**:1-bit 权重误差 E=W−Q1 是**逐元素高维噪声**(≈满秩)。低秩 SVD 只覆盖 <1% 能量,rank-16 只补 **+1.8 点**(死路)。
- ✗ **全残差量化能到 80% 但那 = 加位 = 加体积**,不是极小体积,不接受。
- ✓ **在输出/行为空间**(final hidden → logits,语法=下个 token 挑什么):rank-1 输出空间 z 在 **held-out 代码上泛化了**(FP 一致率 79.5%→82.1%,+2.6),而权重残差 z 不泛化。**证明语法结构低维、可找。**

### 3.2 但强度不足 + 目标问题(实测)
| 实验 | 结果 |
|---|---|
| z 对齐 FP hidden(160 tok) | FP 一致率 +2.6(rank-1 即够,高秩过拟合);**真准确率不涨甚至微降**;NLL −2% |
| z 对齐真值 token(head-row 差) | 真准确率全 +0.0 或 −2.6,**无提升** |

- **根因诊断**:held-out 39 token → 每 token = 2.56 点,所有 ±2.6 **= ±1 token = 噪声**。
- **更深的道理**:若低秩校正能从 1-bit 的 hidden 预测对真值,1-bit 自己就该预测对了。**准确率 gap(74%→82%)是 FP 的额外能力,低秩校正补不动。**

### 3.3 判决
**输出空间低秩"隐形的手"存在但很弱** —— 能让 1-bit 更像 FP(装饰性),补不回真质量。**极小体积修正的天花板 = 几个点(还可能是噪声);到 80% 必须加位。** 这就是所有历史 NO-GO 撞的墙,本轮用用户的方法精确量化了。

## 5. 落地路径(不浪费时间的正解)

**停止磨低秩 z(已判弱)。真正能落地的是逐层动态混精度:**

1. **按 §2 表配位**:L4/7/8/12/15/17 真 1-bit;差层 + 深层 2-bit(GO2B);其余 1-bit + joint-LS 编程 scale。
2. **量化器**:`deepseek4-quantize` 已有 `--go1b-layers A:B`;需扩成**按层 relL2 阈值自动配 1b/2b**(消费端 §2 表)。
3. **backbone 保持高精度**(FP8/Q8),不量化(mono-mixed 就是这结构 = PPL 6.47)。
4. **验证**:`bench_ds4.sh`(ds4 引擎 PPL + 生成,测=部署);目标 PPL <10、go 前 5 题过。
5. **体积**:6 层 1-bit + 37 层 2-bit ≈ 介于纯 1-bit(42.5G)和纯 2-bit 之间,双机 ≤12G/机 可跑。

## 6. 避坑清单(铁律)

- **别信 teacher-forced + cos/尾巴重叠指标衡量 sub-2-bit**,能灌水 10⁶×。只认 R²(routed-only)+ 部署 PPL + held-out 泛化。
- **joint-LS 输出最优 scale 是 1-bit 命门**,朴素 mean|w| 是非起点。
- **深层必须 ≥2-bit**,平铺 1-bit 部署必崩(PPL 1620万)。
- **极小体积低秩隐变量补不回 1-bit**;别再在这上面磨。质量需要位。
- **测量样本要够**(held-out ≥100 token),否则全在噪声地板。
- **单机跑全模型 offload 会内核 panic**;必须双机层切片 + 外部内存看门狗,≤12G/机。
- **量化只从原始 HF**,禁用 q2/mono 当模版;q2/hf 原始模型永不删。
