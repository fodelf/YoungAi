Cache penetration (缓存穿透): queries for keys that exist in neither the cache nor the database bypass the cache on every request and hammer the database. Standard defenses: cache a short-TTL negative entry for keys known to be missing, or put a Bloom filter in front of the cache to reject impossible keys before they reach the database.
---
Cache breakdown / stampede (缓存击穿): a single hot key expires and many concurrent requests all miss and rebuild the same value at once. Fix with singleflight so only one rebuild runs while the rest wait for its result, plus jittered TTLs so hot keys do not all expire together.
---
go vet examines Go source code and reports suspicious constructs using static analysis without running the code: Printf-family calls whose arguments do not match the format verbs, unreachable code, struct tags that are malformed, and copying a sync.Mutex by value.
---
gofmt rewrites Go source into the single canonical formatting (indentation, spacing, alignment) so review diffs are about logic, not style. Editors usually run it on save; gofmt -l . lists files that differ from canonical form.
---
A race condition is fixed only when a race detector confirms it: run go test -race on the affected package. Compiling successfully proves nothing about concurrency; only the -race run, passing, is evidence the data race is gone.
---
Binary search on the answer works when feasibility is monotonic: if a candidate value is feasible then every larger (or smaller) value is too. Search the boundary between feasible and infeasible in O(log range) by checking feasibility at the midpoint each step.
---
Reading a file before editing it is mandatory: you cannot correctly edit a line you have not seen. First read the file named in the error or task, look at the exact line, then make one minimal change to that line. Editing blind produces wrong patches.
---
A failing test names the file and the line number of the failure. The next step is to open that exact file and read that exact line, understand why it fails, then make the smallest fix that addresses the named line before re-running.
---
Commit messages state what changed and why, not how. The how is already visible in the diff; the message exists to record the reason a change was made so a future reader understands the intent, not to re-describe the code line by line.
---
Singleflight ensures only one execution of an expensive call happens at a time for a given key: concurrent callers for the same key wait for and share the single in-flight result, which prevents a cache stampede from launching many duplicate rebuilds.
---
Cache breakdown (缓存击穿) is when one hot key expires and a burst of concurrent requests all miss at once and rebuild the same value together. Defend with singleflight (one rebuild, others wait and share it) and by not expiring hot keys simultaneously.
---
A stack matches balanced parentheses: push every opening bracket, and on each closing bracket pop and check it matches the expected opener. The string is valid only if every close matches and the stack is empty at the end.
---
The two-sum pattern uses a hash map from value to index: for each number, check whether target minus that number is already in the map; if so return the two indices, otherwise store the current number and index and continue.
---
Merge sort merges two sorted slices with two pointers: compare the fronts, append the smaller, advance that pointer, and when one slice is exhausted append the rest of the other. It runs in O(n log n) time.
