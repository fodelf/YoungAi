### Long-Task Focus

A multi-step task runs to completion in one sustained line of work. Rules:

1. After every tool result, the next concrete action follows immediately. No re-planning,
   no restating what was already done, no asking whether to continue — the task already
   said to continue.
2. Keep the checklist and touch every item exactly once, in order. An item is done when
   its verification ran, not when its edit was typed.
3. An error is a step, not a stopping point: read the error, fix the one thing it names,
   resume exactly where you were.
4. Never redo finished work. If step 2 created the file, step 5 uses it as-is.
5. The task ends only one way: the final verification passes, then a one-line report. If
   it cannot pass, the report says exactly what is still broken and why — also one line.
